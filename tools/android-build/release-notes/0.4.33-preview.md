# Тропник 0.4.33-preview

Этот выпуск исправляет повторный выбор направления одним нажатием в общем картографическом движке. При отпускании указателя карта могла сначала выбрать нужную территорию, а следующий браузерный `click` того же жеста попадал в уже переместившийся маркер другого направления. В подтверждённом веб-сценарии выбор Иркутской области так переключался на Байкал. Одно нажатие теперь завершается одним выбором; последующий самостоятельный жест и клавиатурное управление остаются отдельными действиями.

Сохранены исправления камеры 0.4.32: масштабирование относительно свободной области с учётом интерфейса, согласование автоматического кадрирования с ручным zoom, быстрые повторные нажатия и ограничения масштаба. Веб и Android используют общий проверяемый runtime собственного движка. Режимы **Рельеф** и **Спутник**, исходные тропы, выбор линии, отдельная ландшафтная сцена и восстановление камеры сохраняются.

Каталог содержит 685 справочных карточек: 624 с исходной геометрией и 61 без подтверждённой линии. Общий слой использует 621 уникальный источник, 22 456 частей и 404 749 вершин. Разрывы линий не соединяются искусственно. Импорт источника не подтверждает полевую проверку, актуальную проходимость или разрешение на посещение.

Офлайн-пакет содержит карточки и исходные линии. Подробная встроенная подложка доступна только для пилотного района; подробное покрытие всей страны и спутниковые снимки требуют сети. Аккаунты, группы, чаты и серверный паспорт требуют отдельно развёрнутого API/PostGIS. Локальная карточка не подтверждает отправку в МЧС.

Это универсальный **preview APK**, `versionCode=16`, с development/debug подписью. Постоянная production-подпись владельца не настроена. Совместимость обновления определяется сравнением package, versionCode и сертификата с фактически опубликованным предыдущим выпуском; при другом сертификате Android отклоняет обновление. Не удаляйте прежнее приложение с нужными данными: нативный перенос закладок, офлайн-пакетов и очереди пока не реализован. JSON-экспорт браузерных планов относится только к браузеру.

Публикация запрашивается отдельно после полного браузерного прогона исправленного общего движка. Сам запрос запускает собственные сборку, JVM/R8-проверки, испытания точного универсального APK и проверку публичных файлов. Результаты предыдущих исходников и выпусков не подставляются вместо этих проверок. Фактические SHA-256, сертификат, source commit и результаты CI добавляются после успешного выпуска. Эмулятор API 35 x86_64 не заменяет испытания физического ARM64, полевого GPS и расхода батареи.
