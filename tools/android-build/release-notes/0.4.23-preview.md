# Тропник 0.4.23-preview

Исправление береговых контуров и подписей карты; согласование Android с веб-выпуском 0.4.23.

- Берег, острова и административные линии строятся из закреплённых исходных границ с детализацией по масштабу. Загрузка и разбор ограничены видимой областью.
- Подписи, допустимые по географическому покрытию, отрисовываются целиком над маской. Проверка геометрии выполняется вне потока интерфейса.
- Проверки выпуска связывают исходный commit, содержимое APK, подпись и фактически установленный в эмулятор universal APK.

Это APK с development/debug подписью. Он не заявляет готовность к магазину или проверку на физическом ARM64-устройстве. Браузерный конструктор сохраняет планы в браузере. Веб-паспорт безопасности и его автономная карточка также принадлежат веб-приложению; нативное приложение не выдаёт их за встроенную Android-функцию.

Работа аккаунтов, групп и серверного паспорта требует отдельно развёрнутого Go API/PostGIS. Локальные черновики не подтверждают подачу или регистрацию в МЧС. Контрольные суммы, сертификат и точный набор выполненных проверок добавляются к выпуску только после успешного CI.
