# Тропник 0.4.18-preview

Исправления отклика карты и проверка нажатия по направлению.

- Разбор координат и вычисление рамки маршрута вынесены из потока интерфейса.
- Вместо отдельного объекта LatLng для каждой вершины сохраняются только четыре границы. Полная исходная линия маршрута остаётся неизменной.
- Ошибка геометрии обрабатывается в карте без падения экрана.
- Инструментальная проверка выбирает направление настоящим касанием карты, затем открывает карточку маршрута и проверяет сведения об ограничениях.
- Сохраняются проверки пикселей 3D-сцены, поворота, масштаба, повторного открытия и восстановления после ошибки.

Веб-версия 0.4.18 исправляет перехват нажатий прозрачным Canvas, увеличивает зону касания точек до 44 CSS px, ускоряет конструктор составных походов и проверяет компьютерную карту отдельно от мобильной.

Это предварительный APK с development-подписью, а не выпуск для магазина. Составной поход открывается в браузерном конструкторе; его планы сохраняются в браузере. Проверка эмулятором не заменяет проверку на физическом устройстве. Точные контрольные суммы, сертификат и исходный commit входят в манифест и отчёты этого выпуска.
