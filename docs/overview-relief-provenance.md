# Локальный обзорный рельеф РФ

Проверено 6 ноября 2026 года. Артефакт предназначен для начального обзора карты и не требует внешнего картографического сервиса при загрузке локальных файлов. Это светотеневая картографическая подложка малых масштабов, а не DEM, спутниковый снимок или подробная офлайн карта троп всей России.

Файлы были получены обычной загрузкой с `raw.githubusercontent.com`, проверены по Git blob SHA из GitHub Contents API, затем дополнительно по SHA-256. Исходник сохранён в `data/overview-relief/raw`, за пределами веб runtime; GitHub inventory исключает каталог `raw`.

Текущая [страница Natural Earth 1:50m Shaded Relief](https://www.naturalearthdata.com/downloads/50m-raster-data/50m-shaded-relief/) описывает grayscale shaded relief на основе уменьшенных SRTM Plus данных и предлагает версию 3.2.0. Эта версия не приписывается фактически использованному историческому файлу. `50M` означает масштаб **1:50 000 000**, а не детализацию 50 метров.

## Преобразование

Генератор `tools/map-package/build-overview-relief.py` берёт значения серого билинейной интерполяцией в центрах пикселей Web Mercator / EPSG:3857. Долгота оборачивается по 360°; производная сетка не разрывает российское покрытие при переходе через 180°.

Alpha берётся из существующего `web/public/data/russia-canonical-area.geojson`, SHA-256 `6731c4ae30d8643df3dc917416769ce4c4be98e1936458c145464e1387e1087b`. Геометрия не меняется. Контур растеризуется с четырёхкратным разрешением и усредняется до пикселя; буфер вокруг территории не добавляется. Пограничный пиксель может быть частично прозрачным, как выборка площади исходного контура.

Тонирование соответствует палитре продукта:

```text
baseRGB = [219, 228, 205]  (#DBE4CD)
outputRGB = round(baseRGB × (0.62 + 0.38 × grayscale / 255))
```

Это только цветовое оформление исходного shading. Цвет не означает тип растительности, диапазон высот, погоду или реальное положение солнца.

## Контракт интеграции

Путь тайла: `/maps/russia-relief/{z}/{x}/{y}.png`. Полная пирамида XYZ, z0–4, размер тайла 256 × 256, RGBA PNG. Все 341 пути существуют, включая 285 полностью прозрачных тайлов; прозрачные тайлы побайтно одинаковы. Непустых тайлов 56, уникальных tile blobs 57. Общий размер PNG — **1 689 348 байт**, крупнейший тайл — 83 358 байт.

- `tilejson.json` — стандартные tile URLs, zoom и attribution.
- `manifest.json` — происхождение, геопривязка, метод обработки, размеры и SHA-256 каждого PNG, контрольные точки.
- `ATTRIBUTION.txt` — локальный текст атрибуции и лицензирования.
- `maxNativeZoom: 4`, рекомендуемый предел отображения слоя `maxzoom: 6`.
- Полные bounds пирамиды: `[-180, -85.0511287798066, 180, 85.0511287798066]`; вне выбранного покрытия пиксели прозрачны.
- Display bounds РФ: `[19.6389282, 41.1858711, 191.0026658, 81.858721]`. Это не `bounds` канонической XYZ пирамиды.
- Для развёрнутой камеры РФ требуется обычный wrap X по `2^z`; `noWrap: true` может отрезать Чукотку на долготах больше 180°.

Слой следует размещать над непрозрачной заливкой суши и под маршрутами, подписями и подробной картой. В браузере автономность после потери сети требует сохранения соответствующих локальных PNG через Service Worker или явный download; само наличие файлов на сервере не означает, что они уже сохранены на устройстве. В APK их можно включить непосредственно в assets без TIFF исходника.

## Проверки

Генерация завершена для всех z0–4. Дополнительно перечитаны все 341 PNG: размер, RGBA mode, байты и SHA-256 совпали с manifest. Все 22 существующие положительные и отрицательные контрольные точки совпали с alpha на z4, включая Калининград, арктический остров, Крым и обе стороны антимеридиана. Четыре пары долготы `lng` / `lng + 360` дали одинаковые координаты пикселя и значения интерполяции. Мозаика РФ осмотрена визуально: рельеф виден, контур и переход через антимеридиан непрерывны.

Это проверки построения подложки, не сертификация географической точности, актуальности местности или навигационной готовности маршрутов.

Воспроизведение при наличии закреплённых source files:

```sh
python3 tools/map-package/build-overview-relief.py
```

Для обычной загрузки отсутствующих файлов по закреплённым официальным URL:

```sh
python3 tools/map-package/build-overview-relief.py --download
```

При ошибке доступа генератор останавливается; источники, прокси или способы аутентификации автоматически не подменяются. Требуются Python 3, NumPy, Pillow и Shapely.
