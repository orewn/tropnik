# Первичные источники и редакционные маршруты: 11 ноября 2026

## Что добавлено

Добавлены **37 справочных карточек для 29 территориальных разделов**, по **47 первичным страницам и паспортам**. Источники — сайты национальных парков, заповедников, музеев, авторов маршрутов и официальные туристические порталы. Дата редакционной проверки указана по `Europe/Moscow`; время получения каждого документа сохранено отдельно в UTC.

Карточки находятся в `web/lib/national-editorial.generated.json`; факты, пределы проверки, решения по правам и контрольные суммы — в `data/catalog/national-editorial-sources.json`.

**Это 37 описаний, а не 37 новых треков.** У всех записей `publicationStatus: reference`, сложность не подтверждена, геометрии и искусственных точек старта нет. Описание подтверждает существование опубликованной программы. Оно не подтверждает полевую проверку, актуальную проходимость, безопасность или получение разрешения посетителем.

Для двух маршрутов найдено актуальное прямое сообщение о закрытии. У «Линий леса» установлен `accessStatus: closed` на зимний период 2026–2027; у «Ехэ гороо» — из-за объявленного парком закрытия туристического сезона с 4 сентября 2026. Остальные записи имеют `accessStatus: unknown`.

## Критерии отбора

Первый поиск охватывал территории, где прежний импорт не давал геометрии: Чукотку, Магаданскую область, ЕАО, НАО, ЯНАО и Туву. После национального обнаружения WMT добавлены описания для предварительных нулевых разделов и областей с вероятными чужими кандидатами из-за прямоугольных границ поиска.

Запись принимается, когда первичный источник описывает существующую пешую прогулку либо явно отделяет пешую часть комбинированной программы. Обещание построить маршрут, фотография достопримечательности, автомобильный тур без пешего участка или виртуальная экскурсия не считаются готовым пешеходным маршрутом.

Геометрия из точек достопримечательностей, схематических изображений и описаний не восстанавливалась. Дорога к месту старта, лодочная доставка и пеший участок учитываются раздельно. Полная длина неизвестного варианта не вычисляется удвоением односторонней дистанции или сложением отдельных отрезков, если это не опубликованный итог автора.

## Геометрия и права

Публичная ссылка на GPX не была принята за лицензию на перераспространение. Для Большой Колымской тропы проверены два исходных файла:

| Источник | Проверка исходного GPX | Решение |
| --- | --- | --- |
| Чёрный ключ | 788 точек, один сегмент; расчётная длина 8,295 км, описание автора — 8 км | Ссылка на автора; файл и линия в каталог не включены |
| Ключ Конгали | 359 точек, один сегмент; расчётная длина 11,595 км, описание автора — 10 км | Расхождение отражено в карточке; файл и линия не включены |
| Спящий рыцарь | Файл на странице подписан «до озера»; описание всей программы включает вершину | Наличие файла не считается геометрией восхождения |

На сайте «Марий Чодра» также обнаружены опубликованные GPX. Для них не установлена явная лицензия на перераспространение; в приложение они не включены.

Контрольные суммы двух изученных колымских GPX и их публичные URL сохранены в журнале источников. Явное разрешение на перераспространение не установлено; файлы использовались только для анализа. Фотографии, схемы и тексты статей не переносятся в приложение. Публикуются краткие самостоятельно написанные описания и ссылки.

Это решение отличается от импорта OSM/WMT: у открытых геоданных есть установленная [лицензия ODbL](https://www.openstreetmap.org/copyright) и отдельные требования к указанию авторства. Для них выполняется собственная проверка источника, территории и геометрии. Наличие официального описания само по себе не повышает геометрию OSM до полевой проверки.

## Проверки данных

Перед записью выполнена независимая проверка всех 37 записей:

- идентификаторы уникальны и не пересекаются с действующими импортированными и редакционными каталогами;
- все `territoryIds` существуют в текущем территориальном справочнике, `regionId` и `regionIds` согласованы;
- `geometryUrl`, `geometry`, `center` и `bbox` отсутствуют;
- подтверждения навигационной готовности, полевой проверки и геометрии в журнале равны `false`;
- у всех 47 первичных документов сохранены URL, время загрузки, объём и SHA-256; контрольные суммы проверены по полученным байтам;
- дополнительные документы всех карточек присутствуют в журнале источников;
- семь неопределённых пеших дистанций остаются `null`, без нулевой длины и вымышленных значений;
- два подтверждённых сообщения о закрытии отражены в `accessStatus`.

## Ограничения и оставшиеся пробелы

Ни одна из этих карточек не добавляет подтверждённую линию на карту. Для полноценного маршрута с навигацией нужны пригодный исходный трек, права на публикацию и отдельная сверка с описанием. При отсутствии этих данных территориальный раздел может содержать полезное описание, оставаясь без геометрии.

Для части первичных сайтов прямой запрос временно возвращал ошибку (в частности, Шорский парк — HTTP 503, отдельная страница Visit Udmurtia — HTTP 404, сайт Ростовского заповедника — HTTP 502; сайт Хинганского заповедника не ответил вовремя). Это зафиксированная неудача получения конкретной страницы, а не доказательство отсутствия маршрутов. Для опубликованных карточек использованы другие доступные первичные страницы. По Кемеровской области выбран действующий маршрут музея «Томская Писаница», по Удмуртии — карточка национального парка в «Заповедном путешествии» с явным описанием расхождений.

Национальный импорт завершён: 337 новых геометрий. После его фильтрации пустыми оставались Коми, Самарская область, Кировская область, Хабаровский край и Марий Эл; для каждой из этих пяти территорий добавлено одно первичное описание. Архангельская и Оренбургская области получили геометрию из импорта, поэтому подготовленные резервные описания не добавлялись ради увеличения счётчика.

Эта подборка не объявляется полным перечнем всех физических пешеходных маршрутов страны. Итоговая пересборка и аудит `data/catalog/national/web-integration-audit.json` подтверждают 680 карточек, из них 614 с геометрией. Все 85 территориальных разделов существующей карты содержат карточки: 53 раздела с геометрией, 32 — только со справочными описаниями, пустых разделов нет. Причины отбраковки и одна ограниченная по размеру ответа загрузка остаются в `data/catalog/national/import-report.json`.

## Независимая проверка национальной геометрии

Воспроизводимый аудитор `tools/import-data/audit_national_independent.py` не импортирует production importer. Все 337 новых геометрий проверены целиком по маске отображения и территориальным полигонам. Для 10 географически и структурно разных примеров выполнена отдельная сверка исходных member ways: идентификаторы, SHA-256 ответа, число сегментов и точек, порядок и все координаты после обратного преобразования Меркатора через `atan(sinh())`. Выборка включает крайние размеры и долготы, а также маршруты Астраханской области, Якутии, Курганской области, Свердловской области, Новгородской области и Красноярского края.

Результат: `passed`, ошибок нет; новые линии имеют положительную длину внутри 44 территорий. Это число относится только к национальному дополнению, а не ко всему прежнему и новому каталогу. Итоговая квитанция: `docs/verification/national-route-independent-audit-0.4.24.json`. В ней сохранены контрольные суммы входных файлов и самого аудитора. Эта проверка устанавливает целостность и географическое соответствие исходным данным; она не является полевой проверкой или подтверждением допуска к посещению.

Повторный запуск из корня репозитория (нужен Shapely; `--raw-root` указывает каталог, содержащий `raw/` из проверенного снимка WMT):

python tools/import-data/audit_national_independent.py --raw-root /path/to/verified-snapshot
