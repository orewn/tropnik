# Конструктор составного похода

Версия: 0.4.15. Страница: `/planner`. В карточке с геометрией доступна ссылка «Составить поход из троп»; `?route=<id>` выбирает первую тропу.

## Пользовательский сценарий

1. Выбрать исходную тропу из каталога или открыть воспроизводимый пример «Поля-Ястребиное → Жёлтый».
2. Указать старт. Конструктор предлагает реальные окончания, развилки и опорные точки колец; точки доступны в списке и на карте.
3. Выбрать связанную тропу и конкретный стык. При нескольких стыках они доступны отдельно.
4. Добавить обязательные точки «Через…» на этапах, выбрать финиш и назначить этапам дни. Между последовательными обязательными точками считается кратчайший путь по исходным рёбрам.
5. Проверить линию, предупреждения и источники; сохранить план в браузере, скачать переносимый JSON или GPX.

Доступно до 20 этапов, 10 обязательных точек на этап и 31 дня. Удаление этапа также удаляет последующие: интерфейс явно называет действие, поэтому не переставляет стыки молча. Дни задаются вручную и не меняют геометрию. Пользовательские заметки о ночёвках не обозначают официально разрешённую стоянку.

## Основания связи

| Основание | Интерпретация | Поведение |
| --- | --- | --- |
| Совпадающая исходная вершина | В источниках есть общая точка | Можно построить непрерывную геометрическую линию; доступ всё равно требует проверки |
| Совпадающие исходные рёбра | Общий участок | Предлагаются концы коридора, выбранная часть учитывается по фактическому прохождению |
| Пересечение без общей исходной вершины | Линии пересеклись в плоскости | Переход остаётся неподтверждённым; отдельные сегменты GPX |
| Близость до 300 м | Возможный переход | Расстояние по прямой показывается отдельно; неизвестный пешеходный переход не добавляется к дистанции |
| Разные компоненты одной тропы | Внутренний разрыв источника | Нет автоматического соединения даже при разрыве меньше 10 м |

Наличие линии не подтверждает проход по одному уровню, отсутствие ограды, переправу или право доступа. Закрытия и ограничения исходных карточек сохраняются в плане.

## Данные и расчёт

Индекс строится из 306 карточек: у 277 есть исходная геометрия, у 29 её нет. В сжатой топологии 9 177 узлов и 8 893 ребра. Найдено 1 014 кандидатов связей: 672 варианта общих участков, 281 пересечение / общая точка и 61 соседство. Эти значения описывают варианты стыков, а не количество безопасных переходов.

Граф объединяет исходные вершины только по точным координатам. Виртуальные точки внутри сегмента привязаны к исходной части и позиции: совпадающие координаты разных частей не создают скрытой связи. В плане хранится упорядоченная последовательность направленных интервалов исходных линий. Длина считается по этой последовательности: реальный повторный проход учитывается повторно, добавление дублирующей карточки само по себе не добавляет её полную длину.

Исходники и рассчитанный граф входят в `sourceDigest`. Для каждого маршрута сохранены SHA-256 исходного файла, отпечаток нормализованных координат, дата и статус доступа. Загружаются только геометрии выбранных этапов, по URL с SHA-256 в параметре; повторная загрузка использует новый ключ. При несовпадении геометрии с индексом экспорт останавливается.

Основные файлы:

- `web/lib/trail-connections.ts` — поиск связей, выбранные точки, путь и восстановление исходных координат.
- `web/scripts/build-trail-connections.mjs` — генератор, `--check` проверяет актуальность результата.
- `web/lib/trail-connections.generated.json` — индекс; примерно 951 КБ исходного JSON / 236 КБ gzip.
- `web/lib/hike-draft.ts` — схема черновика, валидация импорта, JSON и GPX.
- `web/components/HikePlanner.tsx` — интерфейс; существующая карта используется в режиме планирования.

Обе производственные сборки проверяют индекс командой `node --experimental-strip-types web/scripts/build-trail-connections.mjs --check`. Pages также проверяет маршрут, загрузчик, настоящий bundle и префикс `/tropnik/`.

## Сохранение и экспорт

План хранится локально в браузере, до 20 сохранённых планов; заполненное хранилище не вытесняет старые записи. Есть открытие, JSON-копия, удаление из списка и отмена удаления в текущем сеансе. Старый JSON можно скачать даже при несовместимом `sourceDigest`. Серверная синхронизация и передача плана участникам в этой версии не реализованы.

Импорт проверяет версию схемы и данных, типы и размер полей, маршрут каждого этапа, принадлежность стартовых и промежуточных точек, выбранный стык между соседними этапами и порядок дней. JSON не подменяет исходные координаты.

GPX сохраняет точный порядок координат, отдельные сегменты на разрывах, метаданные этапов / дней / обязательных точек / заметок. XML-текст экранируется. Высоты и времена прохождения не создаются. Экспорт проверяет, что расчёт относится к текущим этапам, стыкам, старту, финишу и `via`.

## Контрольные случаи

| Сценарий | Ожидаемый результат |
| --- | --- |
| «Поля-Ястребиное → Жёлтый» | 1 945,477 + 1 515,485 = **3 460,962 м**, один непрерывный сегмент из 222 исходных точек |
| Обратное направление примера | Точный обратный порядок координат, та же длина |
| Маршрут `kavkaz-8a` | Исходные две компоненты и разрыв **8,753 м** сохраняются |
| Малое / Большое кольцо тисо-самшитовой рощи | Коридор **453,648 м** представлен двумя концами |
| Дублирующиеся кольца `13523771` / `13523772` | Длина общей сети **3 146,707 м**, исходные дубликаты не удваивают граф |
| Радиальный выход с `via` | Повторный участок учитывается повторно; одинаковые старт и финиш без промежуточных точек не дают готовый нулевой поход |
| Изменение дня | Длина и порядок координат не меняются |
| Новая геометрия / старый индекс или изменённый `via` / старый расчёт | Экспорт отклоняется с понятным сообщением |

Поведенческие тесты находятся в `web/tests/trail-connections.test.mjs` и `web/tests/hike-draft.test.mjs`.

## Границы первой версии

Конструктор использует имеющиеся линии и кратчайшие пути через явно выбранные точки. Он не строит отсутствующие переходы, не выбирает автоматически обход полной петли и не оценивает нагрузку по дням, продолжительность, высоту, водные препятствия или допустимость ночёвки. Полноценная трёхмерная сцена для составного пути не включена. Эти ограничения отражены в интерфейсе и не меняют доступность основной карты.
