# Тропник — сервисная дизайн-система

Версия интерфейса: `0.4.13`.

## Принцип

Интерфейс должен восприниматься как один спокойный сервис, а не как набор отдельных экранов. Карта остаётся главным рабочим инструментом, а навигация, карточки, формы, истории и справочные страницы используют одинаковую иерархию:

1. действие пользователя;
2. проверяемый контекст;
3. ограничения и безопасность;
4. вторичные подробности.

## Палитра

- основной фон — тёплый минеральный `paper/canvas`;
- рабочие поверхности — почти белые, без чистого холодного белого;
- основной акцент — тёмный лесной зелёный;
- навигационный и информационный акцент — охра;
- вода и холодные состояния — приглушённый сине-зелёный;
- ошибки не окрашивают весь экран: красный используется только для локального состояния и текста действия.

Контраст текста и интерактивных состояний не должен зависеть только от оттенка. Активное состояние всегда имеет минимум два признака: фон или обводку плюс изменение текста/иконки.

## Геометрия

- touch-цели — не меньше `44×44 px`;
- основные действия — высотой `48 px`;
- радиус контролов — 10–14 px;
- карточки имеют более выраженный нижний правый радиус, но не меняют геометрию при hover;
- обводки тонкие и видимые на светлом фоне;
- тени обозначают уровень поверхности, а не украшают каждый блок.

## Иерархия поверхностей

1. **Canvas** — общий фон страницы.
2. **Quiet surface** — группировка навигации и вторичных блоков.
3. **Working surface** — формы, карточки маршрутов и контент.
4. **Elevated surface** — модальные окна, меню слоёв, системные уведомления.

Одновременно на экране желательно не более трёх уровней тени.

## Навигация

Десктопная навигация собрана в одну спокойную поверхность. Активный раздел выделяется отдельной карточкой внутри неё; декоративные треугольники и плавающие точки не используются.

На мобильном меню:

- занимает оставшуюся высоту `100dvh`;
- учитывает safe area;
- блокирует прокрутку документа;
- удерживает клавиатурный фокус внутри;
- закрывается по Escape, изменению ширины и выбору ссылки.

## Главная страница

После карты пользователь видит не рекламный текст, а три продуктовых обещания:

- происхождение и ограничения данных видны;
- ключевые материалы можно сохранить без сети;
- маршрут, состав и сроки можно собрать в паспорт безопасности.

Следующий блок объясняет последовательность подготовки. Каталог направлений завершает сценарий, а не дублирует карту.

## Карта

Картографические стили владеют:

- географическими якорями;
- положением маркеров;
- безопасными областями подписей;
- камерой;
- контролами карты.

Глобальный сервисный слой не содержит селекторов `region-marker`, `trail-marker`, `map-anchor` или `map-label`. Это защищено тестом.

## Движение

- анимации интерфейса длятся 120–220 мс;
- меняются только `transform`, `opacity`, цвет, обводка и тень;
- бесконечная анимация не используется для обычных элементов управления;
- `prefers-reduced-motion` отключает декоративное движение;
- hover применяется только при настоящем точном указателе.

## Адаптивность

Обязательные профили приёмки:

- 320×640;
- 390×844;
- 412×915;
- 844×390;
- десктоп от 1280 px.

Проверяются:

- горизонтальное переполнение;
- размеры touch-целей;
- safe area;
- перенос длинных русских названий;
- мобильное меню;
- нижняя панель карты;
- отсутствие дрейфа географических якорей;
- отсутствие залипшего touch-hover;
- поддержка forced colors и reduced motion.

## Владение стилями

- `tropnik-system.css` — базовые компоненты и типографика;
- `interface-refresh.css` — палитра и картографический визуальный контракт;
- `map-ui-release.css` — геометрия и адаптивность карты;
- CSS Modules — конкретные продуктовые поверхности;
- `final-polish.css` — только общие guardrails, accessibility и безопасные состояния.

Новый глобальный слой не добавляется, пока задачу можно решить в существующем владельце или CSS Module.
