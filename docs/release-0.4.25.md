11 ноября 2026 года. **Android 0.4.25-preview опубликован и проверен по точным общедоступным байтам. Окончательный Pages workflow с новым universal manifest выполняется; успех финального сайта пока не заявляется.**

## Что завершено

Веб-приложение, автономный просмотрщик и Android используют общий собственный движок карты. В 0.4.25 изменено распределение запросов источников: один слот обслуживает одно чтение основного тайла либо одного соседа рельефа. После чтения слот доступен другим нужным данным; частично собранный рельеф остаётся в общем ограниченном бюджете. Потребители одного адреса разделяют исходные байты и не занимают отдельные слоты ожидания одной загрузки.

Сохранены три параллельных сетевых запроса, шесть подготовляемых payload, один декодер, 8 MiB на один тайл вместе с соседями и прежние пределы очереди и кэша. Все предусмотренные соседние измеренные высоты, их координаты, исходные разрешения, DPR, сетка, маска, слои и графический renderer сохранены. Дополнительный экспериментальный `clearRect` из истории разработки не входит в итоговую версию.

[PR 18](https://github.com/orewn/tropnik/pull/18) влит как `b705c20378c7d5cab7a0eaccbd6b59158c7291d0`. Общий runtime после принятого кандидата `a27bb9ddffcbc41554479d32b7c556d0ca60f55f` не изменился. SHA-256 runtime source inputs: `7826b203d11de22542fca57f1b548cff72dcb8a00664f1fb30779165719ace6a`.

## Сайт: окончательная проверка

В [коммит 4b17b08c](https://github.com/orewn/tropnik/commit/4b17b08c56b7d4ce3d46d33db988d61b44c62c7e) перенесены только точный universal manifest и фактический публичный Android proof. Источник APK остаётся `b705c20378c7d5cab7a0eaccbd6b59158c7291d0`; веб-сборка выполняется из `4b17b08c56b7d4ce3d46d33db988d61b44c62c7e`.

[Окончательный Pages workflow 43101003523](https://github.com/orewn/tropnik/actions/runs/43101003523) должен пройти полный исходный browser gate, привязку его отчёта к точной сборке, публикацию и проверку общедоступного сайта. Публичный sourceCommit/buildId и заново скачанный APK будут проверены после deploy; успешный результат этого этапа пока не заявляется.

Предварительный [Pages для b705](https://github.com/orewn/tropnik/actions/runs/43093581461) завершился FAILURE во время проблем GitHub. API предоставляет только пропущенный deploy job и не предоставляет build job; фактическое прохождение браузерного gate для этого запуска не заявляется. Он также использовал предыдущий APK manifest.

Полная [приёмка кандидата](https://github.com/orewn/tropnik/actions/runs/43090521212) и [исполнение его Android-тестов](https://github.com/orewn/tropnik/actions/runs/43090527490) были отдельными предварительными этапами. Для окончательной публикации сайта требуется собственный результат 43101003523.

## Ошибка выгрузки и завершённое восстановление Android

Первая device job `130779797114` выполнила реальные 8/8 тестов, но upload отчётов завершился ошибкой: после пяти запросов `CreateArtifact` получал HTML `<!DOCTYPE` вместо JSON. Все исходные шаги закончились к 20:29:26 UTC, а терминальный статус стал доступен через API только в 21:02. В 20:56:35 штатный rerun был отклонён HTTP 403, потому что GitHub ещё считал run работающим; этот отказ не обходился.

После независимого подтверждения terminal status и чтения реального журнала в 21:03:44 принят один ограниченный повтор только device job. Job `130787519259` повторно выполнила 8/8 сценариев без пропусков и сохранила device artifact `13890997357`. Она скачала исходный build artifact `13890865289` с прежним SHA-256; APK не пересобирался и не переподписывался. Новый ID build job в attempt 2 представляет прежний результат с исходными временем исполнения и артефактом.

Далее publisher `130789827245` и независимый public verifier `130790401398` завершились SUCCESS. Публичное свидетельство записано в 21:09:24 UTC. Сохранены [наблюдение до закрытия заданий и первоначальный HTTP 403](verification/release-0.4.25-upload-blocker.json) и [фактическое восстановление с исходными строками ошибки и политикой повтора](verification/release-0.4.25-recovery.json). Они являются историей диагностики, а не заменой настоящих build/device/public receipts.

На [официальной странице GitHub Status](https://www.githubstatus.com/api/v2/summary.json) при проверке около 21:05 UTC Actions и Pages отмечены как major outage; инцидент `dvy0t3mvh1lg` расследуется. Это отдельное сообщение поставщика. Точная внутренняя причина более раннего HTML-ответа CreateArtifact по нашему журналу не устанавливается.
## Состав и границы preview

Каталог содержит **680 справочных карточек: 614 с исходной геометрией и 66 без линии**. Представлены 85 территориальных разделов существующего слоя карты и 15 туристических направлений; геометрии есть в 53 территориальных разделах. Значение 100 групп в Android metadata означает 85 + 15. Одна учебная карточка учитывается отдельно. Покрытие разделов не означает перечисление каждой физической тропы, полевую проверку или подтверждённое разрешение посещения.

Подробная автономная подложка ограничена пилотной областью; подробные данные других районов поступают по сети. Продолжительность полной загрузки зависит от ответов внешних источников. Изменение очереди не является гарантией фиксированного времени для любого подключения. В программном настольном рендере возможны колебания интервалов кадров; стабильные 60 FPS и аппаратная производительность телефона не заявлены.

Go API/PostGIS, почта и серверные сценарии аккаунтов и групп не развёрнуты. Статический сайт не имитирует их работу. Конструктор походов Android открывает в браузере, где хранятся планы.
