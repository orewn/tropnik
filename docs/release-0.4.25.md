# Тропник 0.4.25-preview: сборка готова, публикация заблокирована

11 ноября 2026 года, состояние на 20:57 UTC. **Исходники 0.4.25 приняты в main, APK собран и сохранён. Финальная публикация Android 0.4.25 и окончательная проверка сайта не завершены.**

Доступны [сайт](https://orewn.github.io/tropnik/) и предыдущий проверенный [Android 0.4.24-preview](https://github.com/orewn/tropnik/releases/tag/v0.4.24-preview). Версия 0.4.25 пока не обозначается как публичный выпуск.

## Принятые изменения

[PR 18](https://github.com/orewn/tropnik/pull/18) принят коммитом `b705c20378c7d5cab7a0eaccbd6b59158c7291d0`; кандидат — `a27bb9ddffcbc41554479d32b7c556d0ca60f55f`. Очередь карты освобождает слот после каждого чтения основного тайла или одного соседа высот. Частично собранный рельеф учитывается в общем лимите, а потребители одного адреса разделяют исходные байты.

Сохранены три сетевых запроса, шесть подготовляемых payload, один декодер, 8 MiB на тайл вместе с соседями, пределы очереди и кэша, все предусмотренные измеренные соседние высоты, исходные разрешения, DPR, сетка, маска и слои. Графический renderer соответствует принятому 1710; отклонённый эксперимент с дополнительным `clearRect` в выпуск не входит.

SHA-256 runtime source inputs: `7826b203d11de22542fca57f1b548cff72dcb8a00664f1fb30779165719ace6a`. Последующие изменения README и журналов не меняют источник APK.

## Текущий блокер GitHub Actions

После завершения всех шагов Android job остаётся `in_progress` с пустым итоговым conclusion; cleanup окончен в 20:29:26 UTC. Аналогично зависла попытка 2 старого [Pages f7](https://github.com/orewn/tropnik/actions/runs/43090337179): полный browser gate и привязка отчёта прошли, upload снимков завершился FAILURE в 20:36:51 UTC, а статический upload пропущен. Эти отрицательные состояния сохранены, успешная публикация не предполагается.

Чтение job logs через подключение возвращает ReadTimeout, annotations пока отсутствуют. Это ограничения доступа к диагностике, а не установленная причина исходного upload failure. Причина не объявляется сетевым сбоем, квотой или отказом приложения без фактического сообщения.

В 20:56:35 UTC сделан один штатный запрос повторить только Android device job на том же build artifact, без пересборки, смены подписи или ослабления сценариев. GitHub отклонил запрос HTTP 403: `The workflow run containing this job is already running`. Новая попытка не создана; повторные запросы и обходы ограничений не выполнялись.

Изолированная read-only диагностика находится в [ветке diagnostics/upload-failure-inspection-025](https://github.com/orewn/tropnik/tree/diagnostics/upload-failure-inspection-025): [первый запуск](https://github.com/orewn/tropnik/actions/runs/43098657591) и [исправленное чтение Azure Range](https://github.com/orewn/tropnik/actions/runs/43098750847). На момент наблюдения оба запуска стоят в очереди без jobs. Они читают точные run/attempt/job/head и ограниченный хвост журнала; приложение не собирают и не меняют. Исправление чтения диагностики не является повтором приёмки приложения.

[Исходные API-наблюдения, заранее записанная политика восстановления и фактический отказ rerun](verification/release-0.4.25-upload-blocker.json) — запись состояния, не подмена тестового receipt.

3. Дождаться штатной публикации 0.4.25 и независимой проверки всех шести общедоступных release assets, исходного архива, подписей и настоящих build/device receipts.
4. Перенести полученный точный universal manifest в сайт, сохранив источник APK b705. Пройти полный Pages gate и проверку реально опубликованного адреса с новым sourceCommit/buildId и SHA-256 скачанного APK.
5. Сохранить реальные public receipts и обновить этот журнал и README после фактического успеха.

## Состав и границы preview

Каталог содержит 680 справочных карточек: 614 с геометрией и 66 без линии. Представлены 85 территориальных разделов существующего слоя карты, из них 53 с геометриями, и 15 туристических направлений. Значение 100 групп Android означает 85 + 15; одна учебная карточка учитывается отдельно. Это покрытие разделов, а не полевая проверка всех физических троп.

Подробная автономная подложка ограничена пилотной областью. Полная загрузка других районов зависит от внешних источников; гарантированное время загрузки для любого подключения и стабильные 60 FPS не заявляются. Go API/PostGIS, SMTP и серверные сценарии аккаунтов и групп не развёрнуты. Конструктор походов в Android открывается в браузере.

[Журнал 0.4.24](release-0.4.24.md) сохраняет предыдущую публичную поставку, исходный 15-секундный отказ первой попытки f7 и отрицательные результаты отклонённого эксперимента. История не заменяется результатами другой версии.
