## Что исправлено

1. Прозрачный Canvas точек больше не перекрывает регионы после возврата к направлениям. Территории и точки используют общий renderer; зона касания точки увеличена до 44 CSS px.
2. На ПК WebGL получает один обработчик выбора с приоритетом точки/линии перед полигоном региона. Убрана блокировка региона при zoom > 7, ограничены повторные hover/resize вычисления.
3. Группы направлений на узком экране увеличивают масштаб при каждом раскрытии. Возврат к обзору России учитывает фактическое положение закрытой панели.
4. Повторное открытие карточки через уже выбранную точку/линию не создаёт лишнюю запись истории. Один возврат снова ведёт в каталог региона.
5. Изменение названия, заметок и дней похода не пересоздаёт маркеры. Подготовленная геометрия сохраняет digest/fingerprint и повторно используется для расчёта пути.
6. Подписки атрибуции, наблюдатели размеров и Service Worker корректно освобождаются; локальные транзакции закрываются при успехе, ошибке и abort.
7. Общие параметры и типы карт собраны в отдельных модулях. GeoJSON проверяется до передачи движку. Неиспользуемый шаблонный UI удалён по графу импортов, используемая инфраструктура connector сохранена.
8. Android разбирает геометрию вне потока интерфейса, вычисляет только четыре экстремума вместо массива LatLng и повторно применяет изменившуюся ревизию того же маршрута.
9. Cache identity Service Worker для Site зависит от версии приложения и содержимого публичных скриптов, стилей и страниц. GitHub Pages дополнительно использует полный build ID. Пользовательские офлайн-пакеты не удаляются обновлением оболочки.
10. Клик по линии привязан к ID фактически показанной геометрии: ожидание следующего маршрута и асинхронное обновление WebGL source не открывают чужую карточку.
11. На телефоне сообщение о недоступном рельефе занимает высоту своего текста. Устранён конфликт CSS top/bottom, растягивавший уведомление поверх карты; кнопка закрытия сохраняет область 44 px.

## Приёмка

Новый browser gate проверяет настоящие касания/клики, выбор маршрута, возврат, повторный выбор региона, перетаскивание, колесо и изменение размеров на мобильном Canvas и desktop WebGL. Нативный сценарий использует MotionEvent по реально отрисованному маркеру, а не прямой вызов callback. Существующие проверки 3D-пикселей сохраняются.

Состояние рабочих модулей, границы проверки и незавершённые внешние интеграции перечислены в [аудите исполнения](runtime-audit-2026-11-09.md). Установочные и security gates — в [аудите зависимостей](verification/dependency-cleanup-2026-11-09.json).

Android остаётся preview с development-подписью. Конструктор открывается в браузере; встроенного автономного планировщика Android в этом выпуске нет.
