# Тропник 0.4.5 — стабильность карты и финальный интерфейс

Дата выпуска: **7 ноября 2026 года**.

## Состав

- нормализация центров маршрутов с учётом покрытия РФ и выбранной территории;
- детерминированный выбор административной области из всех features под курсором;
- четырёхсторонняя раскладка подписей с учётом плавающих карточек, панели, controls, сообщений, легенды и credits;
- повторная раскладка после загрузки шрифта, изменения размеров и состояния мобильной панели;
- русский → локальный → латинский порядок картографических названий;
- стабильный terrain без автоматического включения при выборе маршрута и без пересборки на каждом zoom;
- гистерезис подробного Canvas-слоя, сохранение декодированных рельефных тайлов и увеличенный tile buffer;
- единая палитра и состояния компонентов в `interface-refresh.css`;
- service worker `tropnik-shell-v13` с проверенной повторной упаковкой manifest обзорного рельефа.

## Правила приёмки

Релиз допускается в `main` только после полного набора `web/tests/*.test.mjs`, TypeScript `pages-preview/tsconfig.json --noEmit`, проверки изменённых файлов ESLint, production build и успешного Pages deploy того же commit. Отдельно проверяются обе реализации карты: MapLibre WebGL и Leaflet/Canvas fallback.

## Не заявляется

Карта не подтверждает доступность тропы, разрешение на посещение или фактическое состояние местности. Полный детальный офлайн-пакет РФ не заявляется. Веб-релиз 0.4.5 не переименовывает и не переподписывает существующий Android preview 0.4.4.
