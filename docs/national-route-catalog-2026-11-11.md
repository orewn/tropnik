# Общероссийское пополнение каталога: 11 ноября 2026 года

В «Тропнике» теперь **680 карточек маршрутов**, из них **614 с исходной геометрией**. Карточки есть во всех 85 территориальных разделах существующей карты; реальные линии есть в 53 из них. Это покрытие каталога по выбранным картографическим территориям, а не заявление о числе современных административных субъектов или о полноте всех физических троп России.

## Что добавлено

| Показатель | До | После |
|---|---:|---:|
| Карточки маршрутов | 306 | 680 |
| Карточки с реальной линией | 277 | 614 |
| Территории с карточками | 23 | 85 |
| Территории с реальной линией | 17 | 53 |

Добавлены 337 OSM relations с 180 042 исходными вершинами и 37 справочных карточек по отдельно прочитанным первичным источникам. Последние представлены в [отдельном обзоре источников](national-route-sources-2026-11-11.md). Описание без полученного трека остаётся описанием: для него не создаются координаты, линия или навигационная готовность.

Все 306 прежних активных карточек сохранились. Даты их источников не обновлены повторным запуском генератора. Все 277 прежних активных геометрий сверены побайтно с опубликованным commit `169b0bee9b2bbdb45adfbe71f4162f35f37344d1`. Геометрия 85 территорий, их исходные атрибуты, подписи, центры и контуры не менялись; обновлена только принадлежность маршрутных линий территориям.

## Как получен новый снимок

Для всех 85 существующих территорий выполнен 101 запрос Waymarked Trails. Насыщенные выдачи по 100 записей разбивались на меньшие области, а диапазон через 180° разделялся до запроса. Получено 980 уникальных кандидатов, включая все 278 отношений прежнего исходного набора. Ошибок поисковой выдачи, оставшихся необследованных подзон, насыщенных конечных ячеек и отсечений общим лимитом не было.

Из 702 новых кандидатов:

| Результат | Число |
|---|---:|
| Принята целиком исходная геометрия | 337 |
| Полная линия не покрывается существующим полигоном отображения | 326 |
| Сохранено прежнее исключение по первичному географическому источнику | 2 |
| Классификация не hiking, foot или walking | 28 |
| Нет пересечения с 85 отображаемыми территориями | 8 |
| Ответ превысил сохранённый защитный лимит 12 МБ | 1 |

Последний случай — OSM relation `1254604`, «European long distance path E9». Это размерный предел, а не временный сетевой сбой. Повторный запрос не выполнялся, лимит не увеличивался. Все результаты, включая этот отказ, сохранены в [отчёте импорта](../data/catalog/national/import-report.json).

Непопадание в полигон может означать зарубежную или трансграничную линию либо ограничение точности выбранного картографического источника. Такие случаи не «исправлялись» обрезанием, переносом точек или искусственными соединениями. Исходные ответы для успешно загруженных отклонённых кандидатов также сохранены.

Waymarked Trails показывает индексированные маршрутные отношения OpenStreetMap. Этот снимок не перечисляет каждую физическую тропу или каждое дочернее отношение и не заменяет проверку доступа на местности. У всех новых линий остаются `publicationStatus: reference`, `fieldVerified: false`, `navigationReady: false`. Сумма длин исходных сегментов не объявляется официальной длиной маршрута; развилки и разрывы сохраняются.

## Проверка и воспроизводимость

- [Аудит исходного снимка](../data/catalog/national/catalog-audit.json) проверил 802 исходных ответа, их размеры и SHA256, соответствие каждого принятого маршрута оригинальным сегментам, все территориальные строки и полный учёт кандидатов. Отдельно выполнена проверка из упакованного архива, без использования рабочего raw cache.
- [Независимый аудит](verification/national-route-independent-audit-0.4.24.json) использует собственное обратное преобразование Меркатора и отдельную проверку географических пересечений. У всех 44 территорий, получивших новые линии, есть пересечение положительной длины; случаев только касания границы нет.
- [Проверка действительного экспорта приложения](../data/catalog/national/web-integration-audit.json) загружает реальные exports `content.ts`, проверяет отсутствие дубликатов, прежние геометрии и даты, новые географические ID и покрытие всех 85 разделов.
- [Повторяемость генератора](../data/catalog/national/generator-reproduction.json) проверена на отдельной временной копии. Повторный запуск даёт те же байты. Два старых зарубежных файла, не входящих в активный каталог, удаляются самим генератором, а не ручным исправлением; общее рабочее дерево при этой проверке не переписывалось.

Архив оригинальных ответов: `tropnik-national-route-sources-2026-11-11.tar.gz`, **7772416 байт**, SHA256 `3510bd4e6c2e889b2e2db31b7e1af9bc64403cb0967cc1e283c330fc2eac4ac1`. Внутри 1604 исходных файла и sidecar: 31 326 645 байт после распаковки. Ответы принятых relations занимают 7 658 877 байт; весь набор relation responses, включая отклонённые, — 30 779 637 байт. Старый raw snapshot шести направлений в этот архив не включён и повторно проверенным не объявляется. Полный [паспорт архива](../data/catalog/national/source-archive.json) содержит инвентаризацию, лицензию и время получения данных.

Исходники получены 11 ноября 2026 года с 00:24 до 01:00 по Москве. В raw sidecar сохраняются точные UTC timestamps; дата загрузки в новых карточках выводится по Москве. Это дата получения данных, а не дата полевой проверки маршрута.

После установки зависимостей и получения архива:

```sh
python tools/import-data/audit_national_catalog.py --archive /path/to/tropnik-national-route-sources-2026-11-11.tar.gz --check
python tools/import-data/refresh_territory_membership.py --check
node tools/import-data/audit_national_integration.mjs --check
```

Последняя команда требует историю Git с указанным baseline commit и установленные зависимости `web/`. Режим `--check` не переписывает датированные результаты. Подробности получения и лицензирования приведены в [инструкции импорта](../tools/import-data/README.md). OSM данные сохраняют © OpenStreetMap contributors и ODbL 1.0; они не становятся независимым подтверждением маршрута из-за повторной доставки через Waymarked Trails.
