# Тропник 0.4.23: подробный берег и автономная карточка

Дата подготовки: 10 ноября 2026 года. Веб-версия: `0.4.23`; Android: `0.4.23-preview`, `versionCode 11`. Основа выпуска: `0ed9122243576df94407ce37fcfced62eafa805c`.

## Карта

- Берег, острова и административные линии используют закреплённые исходные границы и несколько уровней детализации. Детальные ячейки загружаются для видимой области. Общая версия покрытия для веба и Android: `e0ce67282bfd3694`.
- Геометрия маски сохраняет точность при приближении. Допустимые по географическому покрытию названия рисуются целиком поверх маски; обработка геометрии Android вынесена из потока интерфейса.
- Декоративные линии границ в Canvas больше не перехватывают нажатия на территорию. Регрессионная проверка использует фактический обработчик клика Leaflet Canvas и попадание в Polygon/LineString.
- Android повторяет запрос покрытия после первого ненулевого размера карты и при изменении размера; новая генерация стиля не использует старую ссылку на покрытие.
- Нативные карты разделяют одни данные покрытия на приложение и один последовательный исполнитель. Декодер строит геометрию прямо из индексов, повторно использует точки, пропускает неиспользуемый нативным стилем слой territory и учитывает декодированные объекты в бюджете кэша. Отдельный резервный индекс подписей создаётся только по запросу; отменённые контроллеры освобождают ссылки.
- Холодный автономный запуск телефона использует доступную Canvas-оболочку. На компьютере WebGL включается только при наличии его зависимостей в кэше; неудачный импорт возвращает Canvas без испорченной сессии карты.

## Паспорт похода

- Автономная аварийная карточка открывает ранее сохранённые сведения, включая контрольные точки и аварийные выходы с координатами. Некорректные и неполные координаты не превращаются в выдуманные точки.
- Действия сохранения, печати и открытия карточки помещаются в отдельную строку с переносом, без сжатия длинных надписей.
- Серверный паспорт связан с составом группы, независимой проверкой, предвыходным контактом, выходом, контрольными сообщениями и возвращением. Истёкший предвыходной контакт до старта требует обновления и возвращает `409 departure_not_ready`; историческое подтверждение уже начавшегося похода сохраняется.
- OpenAPI описывает восемь safety endpoints и двадцать safety-схем, включая доступ к персональным данным, версии и повторение запросов.

Локальный черновик и личные отметки не подтверждают регистрацию в МЧС. Автономная страница не отправляет уведомление и не вызывает спасателей. Серверная интеграция требует отдельно развёрнутого Go API/PostGIS и эксплуатационной настройки; публикация статического сайта сама по себе её не включает.

- [Android CI 42830779310](https://github.com/orewn/tropnik/actions/runs/42830779310) успешно собрал APK и выполнил 59 JVM-тестов. На эмуляторе ожидание начальной готовности карты превысило лимит, а повторное открытие сцен исчерпало Java heap. Публикация была пропущена; этот диагностический APK не является готовым выпуском. Исправление выделения памяти реализовано и проверено по исходникам и подготовке ресурсов; следующая компиляция и повторный прогон с тем же heap 192 МиБ ещё требуются. Добавлены три JVM-регрессии для совместного использования точек, декодированного бюджета и отмены, а также координатного шва ±180°.

## Загрузка APK на сайте

Страница и инструменты Pages выбирают файл из проверенных метаданных: отдельный ARM64 либо универсальный APK. Для universal дополнительно обязательны три точные ABI, контрольная сумма именно проверенного пакета и свидетельство совпадения установленного APK с артефактом сборки. Страница показывает версию и совместимые архитектуры. В публикацию Pages попадает только выбранный файл.

В Site большие APK выдаются перенаправлением `/downloads/[file]` на закреплённый публичный release GitHub. Перенаправление допускает только выбранное имя и версию; исходящий адрес не берётся из запроса. APK исключаются только из сгенерированных статических файлов Site, где установленный Wrangler ограничивает один asset 25 МиБ. Pages сохраняет локальный файл с проверкой полных байтов и SHA256. Сборка Site с этим маршрутом прошла: маршрут классифицирован как API, файлов сверх лимита в static output нет.

## Условия публикации

На момент подготовки этого документа публикация и CI ещё ожидаются. Локальные проверки не заменяют компиляцию Android, эмулятор и проверку публичной сборки. Итоговые ссылки, SHA, размеры и подпись добавляются только после получения фактических артефактов.

Android pipeline собирает универсальный APK для `arm64-v8a`, `armeabi-v7a`, `x86_64` и отдельный ARM64 APK. Публикация `v0.4.23-preview` разрешена после семи сценариев эмулятора с проверкой идентичности установленного universal APK. Это preview с development/debug подписью; совместимость обновления поверх прежней сборки не обещана. Веб-паспорт не заявляется встроенной нативной функцией Android.
