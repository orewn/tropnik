# Тропник — веб-карта и объёмный ландшафт

Рабочий веб-проект на React/Vinext и MapLibre. Главная страница — карта и каталог реальных справочных маршрутов; `/terrain/landscape.html` — самостоятельная сцена Бзерпинского района с данными и шрифтами внутри файла.

## Разработка и сборка

Требуются Node.js ≥22.13 и версия pnpm из `packageManager`. Канонический lockfile — `pnpm-lock.yaml`. В среде ChatGPT используйте установленный workflow Sites для зависимостей, preview, сборки и публикации.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm exec tsc --noEmit
pnpm build
```

`build` локально создаёт стиль карты, пересобирает самостоятельную сцену из актуального renderer, проверяет и обновляет офлайн-пакет, проверяет силуэты направлений и запускает основной build. Генерация не требует сети или соседнего каталога data. Это предотвращает расхождение встроенного HTML и карты. Android-обвязка находится в соседнем проекте и также встраивает этот renderer через свой проверяемый генератор.

Подробности поддерживаемой среды и публикации: [vinext-runtime.md](docs/vinext-runtime.md). При работе через Sites следуйте текущему skill, а не старым локальным runtime-путям.

## Главные части

- `public/terrain/terrain-renderer.js` — независимый WebGL2 renderer, материалы, свет, затенение, маршруты и Canvas fallback. Без стороннего 3D движка и внешних запросов из самого renderer.
- `lib/terrain-preparation*` — один Worker для производных данных и общий готовый результат. При отказе Worker — отменяемый расчёт небольшими порциями.
- `lib/map-resource-pool.ts` и `map-transport.ts` — ограниченный общий кэш предзагрузки. MapLibre получает копии изменяемых/передаваемых буферов; отмена одной карточки не отменяет работу другой.
- `components/TerrainScene.tsx` — прогрев реального кадра, жизненный цикл и измеренные отступы от панели.
- `app/map-design.css` — типографика и оформление карты. `RegionArtwork` берёт силуэты из сохранённых геоданных.
- `scripts/landscape-bootstrap.js` — жизненный цикл самостоятельной сцены, включая отмену подготовки при уходе со страницы и сохранение готовой сцены в bfcache.

## Данные и границы результата

Сетка 513×513 восстановлена из сохранённых DEM тайлов Mapterhorn/Copernicus GLO-30. Высоты сохраняют масштаб 1:1. Цвет, фактура, освещение и боковой срез условные; это не актуальная спутниковая съёмка или геологическая модель. Лицензии и происхождение доступны в `/sources` и `public/terrain/`.

Главный сервер социальных функций не подменяется локальными выдуманными пользователями. При отсутствии подключения интерфейс сообщает об этом. Публичные справочные данные отдельно от приватного API.

## Проверки качества

66 автоматических проверок охватывают API policy, готовность сервера, общий кэш, worker reuse/cancel/retry, маршрут на реальном LOD, стабильный drawing buffer, camera fit, восстановление контекста и lifecycle самостоятельной сцены. TypeScript проходит.

`scripts/record-terrain-gles.mjs` + `scripts/replay-terrain-gles.py` проверяют реальные GLSL программы через native EGL/GLES. Это тест движка, не браузер и не измерение FPS телефона. В текущем проходе 10 шейдеров и 5 программ скомпилированы/связаны, GL errors отсутствуют.

Полная визуальная приёмка браузерного интерфейса и длительный прогон на Android-устройстве ещё требуются. В текущей среде браузерный runtime недоступен; software Android AVD не завершил boot. Отсутствие ошибок в тестах не является обещанием нулевых лагов на любом устройстве.

Ограниченные тени используют 32/48 запросов в зависимости от профиля. Для LOD есть гистерезис, но нет геометрического morph между уровнями. При сильном масштабировании переход всё ещё следует оценивать на реальном GPU. Canvas fallback сохраняет данные и основной свет, но имеет упрощённый материал и меньшую детализацию.
